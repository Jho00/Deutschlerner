# Deutschtrainer

Автономный тренажёр немецкого с двумя разделами.

## Модальные глаголы

- 312 упражнений по `können`, `müssen`, `dürfen`, `sollen`, `wollen` и `mögen`;
- ввод формы с клавиатуры и задания с вариантами ответа;
- фильтры по времени и глаголу;
- справочная таблица спряжения;
- сессии, серии верных ответов и статистика;
- сохранение прогресса в `localStorage` браузера.

## Существительные A1–A2

- 600 слов в 15 темах с определёнными артиклями и русскими переводами
- карточки с выбором артикля по одной теме или по всему словарю в случайном порядке
- практика артиклей в предложениях для Nominativ, Akkusativ, Dativ и Genitiv
- тест из 30 случайных слов из всего словаря — 20 на словарный артикль и 10 на артикль в контексте
- прогресс по правильным ответам в карточках сохраняется в браузере
- переключатель на карточке показывает или скрывает перевод слова либо целого предложения

## Запуск

Откройте `index.html` в браузере. Сервер и установка зависимостей не нужны.

## GitHub Pages

В настройках репозитория откройте **Pages**, выберите **Deploy from a branch**, затем ветку и каталог **/(root)**. Эти же файлы можно загрузить в корень любого статического хостинга.
